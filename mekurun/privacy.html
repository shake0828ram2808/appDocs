ピコとめくって について

「ピコとめくって」は、小さなお子さま向けのカードめくりあそびアプリです。キャラクターの「ピコ」といっしょに、カードをめくって楽しく遊べます。

「そろえる」「みつける」「めくる」の3つのあそびかたがあり、おぼえる力や集中力を、遊びながら自然にはぐくめることを目指しています。

動作環境

  • ✓ iPhone・iPad のアプリとして、またスマートフォン・タブレット・PC のブラウザで動作します。
  • ✓ インターネット接続は初回読み込み時のみ必要です。一度開いたあとはオフラインでも遊べます。

あそびのデータについて

  • ✓ ゲームの進行やスコアなどのデータは、お使いの端末内でのみ処理され、外部に送信されることはありません。
  • ✓ アカウント登録やログインは不要です。

個人情報について

  • ✓ 本アプリは、氏名・メールアドレス・住所などの個人情報を一切収集しません。
  • ✓ アカウント登録やログインは不要です。
  • ✓ お子さまの行動履歴やプレイ情報を外部サーバーへ送信することはありません。

データの保存について

  • ✓ ゲームの進行やスコアなどのデータは、お使いの端末内でのみ処理されます。
  • ✓ これらのデータが外部のサーバーや第三者に送信されることはありません。

広告・外部サービスについて

  • ✓ 本アプリには広告は表示されません。
  • ✓ Google Analytics・Firebase などのアクセス解析ツールは使用していません。
  • ✓ サードパーティ製のSDK・トラッキングライブラリは一切組み込まれていません。
